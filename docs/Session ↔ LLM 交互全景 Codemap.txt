  ---
  技术框架与库

  框架/库: Effect
  用途: 全局核心：依赖注入(Layer)、错误处理(Effect.gen)、资源管理、并发控制
  ────────────────────────────────────────
  框架/库: Zod
  用途: Schema 校验：消息结构、工具参数、Provider 配置
  ────────────────────────────────────────
  框架/库: AI SDK (Vercel)
  用途: LLM 统一接口：streamText()、ModelMessage 格式、工具调用协议
  ────────────────────────────────────────
  框架/库: Hono
  用途: HTTP Server（Session 通过此对外暴露 API）
  ────────────────────────────────────────
  框架/库: Drizzle ORM
  用途: SQLite 持久化：Session/Message 存储
  ────────────────────────────────────────
  框架/库: SolidJS
  用途: TUI/Web 渲染层（Session 状态驱动 UI 更新）
  ────────────────────────────────────────
  框架/库: MCP (Model Context Protocol)
  用途: 外部工具集成协议

  关键设计特征：
  - Effect 贯穿全流程，无 try/catch，所有副作用通过 Effect 编排
  - 消息模型使用 MessageV2 内部格式，调用 LLM 前转换为 AI SDK 的 ModelMessage
  - 工具系统采用注册制，按 Agent 权限动态过滤可用工具集
  - 对话压缩(compaction)在 token 超限时触发，生成摘要替代历史消息
